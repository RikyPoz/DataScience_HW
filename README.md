To get this project up and running on your local machine, follow these instructions.

To launch the main application, execute the core script from your terminal: python main.py

The repository includes a dedicated notebook for data exploration: analysis.ipynb.
This file serves as a supporting document used for Explorative Data Analysis. 
You can open it using Jupyter Lab, Jupyter Notebook, or VS Code to view data visualizations and initial insights.

Before running the project, you need to install the following dependencies. 
You can do this using pip: pip install pandas numpy matplotlib seaborn scikit-learn nltk torch
